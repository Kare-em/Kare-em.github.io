    Как я работаюHow I work

    Пять шагов от вашей идеи до плеибла, который проходит модерацию сети с первого раза.Five steps from your idea to a playable that passes network moderation on the first try.

    ШАГ 1 · ВЫ ПРИСЫЛАЕТЕSTEP 1 · YOU SEND

    Идею, референсы и артIdea, references and art

    ТЗ, ссылки на конкурентов, ассеты игры, прошлые плеиблы. Референсы читаю буквально: композиция и раскладка уровня — как на картинке, а не «по мотивам». Неясное в геймдизайне уточняю до старта, а не после.Brief, competitor links, game assets, past playables. I read references literally: composition and level layout match the picture, not “inspired by”. Game design questions get settled before the start, not after.

    Нет ассетов? Соберу и доработаю в Photoshop и Blender.No assets? I’ll put them together and polish them in Photoshop and Blender.

    📄ТЗ.pdfbrief.pdf 🎬reference.mp4 🖼ui_kit.psd 📦assets.zip
    ШАГ 2 · АРХИТЕКТУРАSTEP 2 · ARCHITECTURE

    Логика с нуля, без костылейClean logic from scratch, no hacks

    Архитектура и весь код проекта на TypeScript (Cocos) или C# (Unity). Тайминги и числа — в конфиге, а версии креатива — данными: один билд, а версия переключается одной строкой в готовом HTML.Architecture and all project code in TypeScript (Cocos) or C# (Unity). Timings and numbers live in config, creative versions are data: one build, and the version switches with a single line in the final HTML.

    // версии креатива — данными, не пересборкой// creative versions are data, not rebuilds
const VERSION_DEFS = {

  short: { levels: 1, timer: 15 },
};
const v = window.__PLAYABLE_VERSION__ ?? 'full';
    ШАГ 3 · ГЕЙМПЛЕЙSTEP 3 · GAMEPLAY

    Сочность, которую видно с первого тапаJuice you feel from the first tap

    Механика, физика (вплоть до Ragdoll), tween-анимации, VFX и звук, шейдеры. Адаптивный UI под портрет и ландшафт, туториал-рука, эндкарта, CTA в стор. 2D и 3D — без разницы.Mechanics, physics (down to ragdoll), tween animation, VFX and sound, shaders. Adaptive UI for portrait and landscape, tutorial hand, end card, store CTA. 2D or 3D — doesn’t matter.

    ШАГ 4 · СБОРКАSTEP 4 · BUILD

    Один HTML под каждую сетьOne HTML for every network

    Упаковка в один файл с учётом требований и лимитов каждой площадки. Текстуры в WebP, контроль веса по отчёту сборки — укладываю в 5 МБ. Аналитика AppLovin, сторонние SDK, Luna Playworks.Packed into a single file that meets each network’s requirements and limits. WebP textures, size tracked by the build report — fits under 5 MB. AppLovin analytics, third-party SDKs, Luna Playworks.

    Проверка живьём и правки за минутыLive testing and fixes in minutes

    Прогоняю собранный билд в браузере как пользователь: тапы, эндкарта, переход в стор.     ПРЕИМУЩЕСТВОTHE EDGE

    AI-агент в команде, а не «поспрашивал нейросеть»An AI agent on the team, not “asked a chatbot”

    Claude Code — мой основной инструмент. Он подключён к редактору Cocos через MCP-мост и работает в проекте как полноценный участник:Claude Code is my main tool. It’s connected to the Cocos editor through an MCP bridge and works in the project as a full team member:

    • сам читает иерархию сцены, правит ноды, префабы и компонентыreads the scene hierarchy and edits nodes, prefabs and components on its own
    • запускает превью, снимает скриншоты, читает логи редактораruns the preview, takes screenshots, reads editor logs
    • после каждой правки — диагностика и чистая компиляцияafter every change — diagnostics and a clean compile
    • сборка, проверка живьём, отчёт по весу и переименование под сети — одной командойbuild, live check, size report and per-network renaming — in one command
    • рутину и аудит ассетов отдаю субагентам, сам — геймдизайн и качествоroutine work and asset audits go to sub-agents; I focus on game design and quality

    FAQ

    Под какие рекламные сети собираешь?Which ad networks do you build for?

    AppLovin, Meta (Facebook), Google, TikTok, Unity, ironSource, Mintegral, Moloco, Liftoff, Vungle, Snapchat, MRAID-совместимые площадки и Luna Playworks. Билд собирается один, файлы под сети раскладываются и переименуются по требованиям каждой площадки.AppLovin, Meta (Facebook), Google, TikTok, Unity, ironSource, Mintegral, Moloco, Liftoff, Vungle, Snapchat, MRAID-compatible networks and Luna Playworks. There’s one build; per-network files are laid out and renamed to match each network’s requirements.

    Сколько времени занимает плеибл?How long does a playable take?

    Благодаря AI-конвейеру путь от идеи до играбельного билда занимает часы, а не дни. Итоговый срок зависит от механики и готовности ассетов — оценю после ТЗ.Thanks to the AI pipeline, going from idea to a playable build takes hours, not days. The final timeline depends on the mechanics and asset readiness — I’ll estimate after the brief.

    Что нужно от вас для старта?What do you need from me to start?

    Идея или ТЗ, референсы (видео, плеиблы конкурентов) и арт игры. Если ассетов не хватает — доработаю в Photoshop и Blender.An idea or brief, references (videos, competitor playables) and the game’s art. If assets are missing, I’ll fill the gaps in Photoshop and Blender.

    Сеть отклонила плеибл — поможешь?A network rejected my playable — can you help?

    Да. Исправление реджектов — часть работы: вес, требования MRAID и API сети, ссылки на стор, поведение CTA.Yes. Fixing rejects is part of the job: size, MRAID and network API requirements, store links, CTA behavior.

    Можно сделать несколько версий креатива?Can you make several creative versions?

    Да, и без лишних сборок: версии описываются данными, а нужная включается одной строкой в готовом HTML. Один билд — сколько угодно вариантов для A/B-тестов.Yes, without extra builds: versions are described as data, and the one you need is switched on with a single line in the final HTML. One build — as many variants as your A/B tests need.
